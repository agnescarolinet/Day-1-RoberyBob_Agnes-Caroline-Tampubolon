1. Prompt Engineering
   Dalam memberi instruksi ke AI, instruksi harus tersusun dengan baik yang terdiri dari: Role, untuk menentukan AI berperan sebagai siapa; Context, untuk menjelaskan latar belakang yang ditanyakan; Task, untuk menjelaskan apa yang akan dikerjakan; dan Format sebagai bentuk hasilnya seperti apa.
2. Git dan Gifthub
   Git adalah alat/sistem yang mencatat perubahan entah waktu dan apa yang diubah, bisa dikembalikan ke versi sebelum-sebelumnya tanpa menyimpan banyak salinan file. Sedangkan gifthub, situs untuk mengimplementasikan sistem tersebut secara online supaya aman dan bisa terkoneksi dengan orang lain.
3. Tiga tempat di Git
   Working directory adalah meja kerja tempat untuk mengedit file. Staging area adalah kardus tempat memilih perubahan yang sudah tersimpan. Git directory adalah gudang tempat menyimpan semua versi secara permanen.
4. Perintah dasar
   git init : memulai pelacakan sebuah folder
   git add . : memasukkan semua perubahan ke staging area
   git commit -m "pesan" : menyimpan perubahan sebagai satu versi yang lengkap
   git remote add origin <alamat> : memberi tau Git alamat Gifthub user
   git push origin main : mengirim hasil kerja ke Gifthub
   git pull origin main : mengambil perubahn terbaru dari Gifthub ke komputer user

Intinya prompt yang jelas ke AI akan menghasilkan hasil yang bagus, menyimpan pekerjaan dengan Git, lalu taruh di Gifthub supaya aman dan bisa dikerjakan bersama
